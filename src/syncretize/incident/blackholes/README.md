

# AGN models

Each model has its own directory containing its generator and example YAML
configuration files.

All models are run from the command line with a yaml parameter file
describing the grid axes, and `--grid-dir`, the directory where the resulting
grid should be stored. The comments in each example parameter file list the
allowed values. The parameter file is stored in the grid's `ParameterFile`
group.

## Broken power-law

A simple implementation of an AGN accretion disc is to assume it follows a broken power-law behaviour. One example of this implementation is [Feltre, Charlot, and Gutkin (2016)](https://ui.adsabs.harvard.edu/abs/2016MNRAS.456.3354F/abstract) who combined this model with photoionisation modelling using 'cloudy'. 

'broken_power_law/generate_incident_grid.py' can be used to generate a grid of incident spectra assuming a three component broken power-law. The grid axes are set using the yaml configuration file. A parameter file replicating the [Feltre, Charlot, and Gutkin (2016)](https://ui.adsabs.harvard.edu/abs/2016MNRAS.456.3354F/abstract) grid is provided (bpl-feltre16).

Example usage:
```
python broken_power_law/generate_incident_grid.py broken_power_law/bpl-feltre16.yaml --grid-dir path/to/grids/
```

## RELAGN

RELAGN is a fully relativistic treatment of BH accretion discs and is described in [Hagen and Done (2023)](https://ui.adsabs.harvard.edu/abs/2023MNRAS.525.3455H/abstract). We use the RELAGN models by parametrising the BH accretion disc using four parameters: BH mass, the accreate rate as a fraction of the Eddington rate, the cosine of the inclination, and the dimensionless spin (a). We set the additional parameters in the model to their default values.

Generating the spectra using this model requires the use of the 'relagn' module available [here](https://github.com/scotthgn/RELAGN). Unfortunately this can not currently be installed directly, instead at present, we must clone the 'relagn' repository to this directory from where we can access the 'relagn' module. The 'relagn' module also requires a working installation of the ['xspec' package](https://heasarc.gsfc.nasa.gov/xanadu/xspec/), whose python implementation is imported within relagn.  

Like the Broken power-law model grids are generated by specifying a parameter file including the grid axes. A variety of parameter files for different axes are available, but these can be adapted.

Example usage:
```
python relagn/generate_incident_grid.py relagn/relagn.yaml --grid-dir path/to/grids/ --num-procs 8
```

## RELQSO

The RELQSO model is a simplified implementation of the more general RELAGN model. See Appendix B in [Hagen and Done (2023)](https://ui.adsabs.harvard.edu/abs/2023MNRAS.525.3455H/abstract) for more details.

Example usage:
```
python relqso/generate_incident_grid.py relqso/relqso.yaml --grid-dir path/to/grids/
```

## QSOSED

QSOSED is a simplified version of the AGNSED model described in [Kubota and Done (2018)](https://ui.adsabs.harvard.edu/abs/2018MNRAS.480.1247K/abstract), by fixing some parameters at the typical values and by including reprocessing. This does not include any relativistic effects that are present in RELAGN/RELQSO. In our modelling the QSOSED model is made using the 'relagn' module by simply setting the spin to be 0 and asking for the non-relativistic spectra. 

Like the Broken power-law model grids are generated by specifying a parameter file including the grid axes. A variety of parameter files for different axes are available, but these can be adapted.

Example usage:
```
python qsosed/generate_incident_grid.py qsosed/qsosed.yaml --grid-dir path/to/grids/
```

## cloudy agn spectrum

`cloudy` has a built-in AGN spectrum, set by its `agn` command (see Hazy 1): a big blue bump with an exponential cutoff at a temperature T, plus an X-ray power law, joined using the optical to X-ray index $\alpha_{ox}$. 'cloudy_agn/generate_incident_grid.py' can be used to generate a grid of incident spectra with this shape.

The grid axes are set using the yaml configuration file, from the blue bump temperature (`blue_bump_temperature`) and the three slopes (`alpha_ox`, `alpha_uv`, `alpha_x`); a single value fixes a parameter instead. Two example parameter files are provided (cloudy_agn and cloudy_agn-limited).

`blue_bump_temperature` can be set on each black hole when using these grids, otherwise the default calculation following [Inayoshi and Maiolino (2025)](https://ui.adsabs.harvard.edu/abs/arXiv:2409.07805/abstract) is used.

Example usage:
```
python cloudy_agn/generate_incident_grid.py cloudy_agn/cloudy_agn.yaml --grid-dir path/to/grids/
```

## cloudy blackbody spectrum

`cloudy`'s `blackbody` command gives a blackbody (Planck) spectrum at a temperature T (see Hazy 1). 'blackbody/generate_incident_grid.py' can be used to generate a grid of incident spectra with this shape.

The grid axis is the blackbody temperature (`blackbody_temperature`), set using the yaml configuration file. Two example parameter files are provided (blackbody and blackbody-limited).

`blackbody_temperature` is not calculated by synthesizer, so it needs to be set when using these grids, either on the emitter or as a fixed parameter of the emission model. For example, setting `blackbody_temperature="shakura_sunyaev_temperature"` on a black hole uses its Shakura-Sunyaev thin disc temperature.

Example usage:
```
python blackbody/generate_incident_grid.py blackbody/blackbody.yaml --grid-dir path/to/grids/
```
